# Pneumonia Detector

A deep learning app that detects pneumonia from chest X-rays using DenseNet121.

## Live Demo
[Try it on Hugging Face Spaces](https://huggingface.co/spaces/mokut/pneumonia-detector)

## Model
- Architecture: DenseNet121
- Dataset: Kaggle Chest X-Ray Pneumonia
- False Negatives: 0
- Threshold: 0.28
